# webflow-to-astro-demo

A test repository for openfabriq's Webflow to Astro factory: it moves the public Webflow template demo at https://flowbase-blog-clone.webflow.io to an Astro site, here.

No Webflow token: the factory reads the published pages only, so its export command and the weekly content sync are removed.

To start: open an issue "Migrate https://flowbase-blog-clone.webflow.io" and add `migration:discover`.
